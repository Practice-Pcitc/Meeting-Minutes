# 文本说话人关联实施计划

- 归档日期：2026-08-16
- 当前状态：进行中
- 当前阶段：阶段一已完成，阶段二接入层已完成，阶段三聚类级确认已完成
- 涉及模块：录音、语音转写、合并文本视图、手动会议记录

## 目标

在不混淆“手动记录中的参会人”和“语音识别得到的说话人”的前提下，为转写文本建立稳定、可扩展的说话人关联能力。

当前先使用手动记录的时间和参会人信息，为最接近的转写文本小段提供人物提示；后续接入说话人分离后，再将匿名说话人聚类映射为真实参会人。

## 核心设计

录音、文本分段、说话人聚类和真实参会人身份分别建模：

1. 录音负责保存原始音频及录制时间。
2. 转写分段负责保存文本及相对录音的开始、结束时间。
3. 说话人聚类只表示同一个匿名声音，例如 `speaker-0`，不直接等同于某位参会人。
4. 说话人映射负责将文本分段或匿名聚类关联到参会人，并记录关联来源与置信度。
5. 手动记录作为时间锚点，只影响时间上最接近的文本小段，不代表整段录音的说话人。

关联来源的显示优先级为：

1. 用户确认
2. 手动记录时间锚点
3. 自动声纹识别

## 阶段状态

### 阶段一：分段模型与手动记录锚点

状态：已完成

已完成内容：

- 后端录音元数据新增 `transcriptSegments`，保存文本、开始时间、结束时间和时间来源。
- 转写结果支持读取 FunASR `sentence_info` 中的真实分段时间与 `spk` 聚类标识。
- 没有真实分段信息的历史录音，会根据录音时长和文本长度生成兼容性估算分段。
- 后端预留 `speakerAssignments`，支持按文本分段或说话人聚类关联参会人。
- 合并文本视图继续按逗号、句号、问号、感叹号和分号细分展示文本。
- 只有带参会人的手动记录才参与头像匹配。
- 每条手动记录只匹配前后 30 秒范围内距离最近的一个文本小段。
- 不再为每个录音片段或无身份文本显示通用人物头像。
- 前端保留原始 ASR 分段 ID，逗号二次切分不会破坏未来的说话人映射。
- 前端已经能够读取预留的分段/聚类身份映射，并按来源优先级选择头像。

验证结果：

- 服务端 `npm run build` 通过。
- 前端 `npm run build` 通过。
- 旧录音元数据保持兼容。

### 阶段二：说话人分离

状态：接入层已完成，模型运行待配置

计划内容：

- 完整录音会按 FunASR 扩展协议请求 `verbose_json`、`spk=true` 和分段时间戳；服务启用 CAM++ 后可直接返回匿名说话人结果。
- 后端已支持把 `sentence_info[].spk` 或 `segments[].speaker` 写入每个 `transcriptSegment.speakerClusterId`。
- 保证多段录音中的聚类标识限定在各自录音范围内，避免误认为跨录音的同一人。
- 合并文本视图会用稳定的匿名编号与颜色区分声音，在身份未确认前不会冒充真实参会人。
- 评估重叠语音、短句和噪声情况下的分离效果。

### 阶段三：身份确认与人工校正

状态：聚类级确认已完成，单分段校正待实现

计划内容：

- 已提供“匿名说话人 → 参会人”的确认界面。
- 已支持修改或清除整个匿名聚类的人员映射；单独修改一个文本小段仍待实现。
- 用户确认结果会持久化为 `speakerAssignments`，来源标记为 `user-confirmed`。
- 手动记录锚点可以提供身份建议，但不自动覆盖用户已经确认的结果。
- 已支持撤销或重新分配，避免错误关联永久污染历史数据。

### 阶段四：可选声纹识别

状态：未开始

计划内容：

- 在用户明确授权后保存参会人声纹特征。
- 自动为匿名说话人聚类推荐参会人，并保存置信度。
- 低置信度结果只作为候选，不直接显示为已确认身份。
- 明确声纹数据的存储、删除和隐私边界。

## 当前限制

- 实时转写文本如果没有 ASR 级时间戳，分段时间仍是按文本长度估算，头像关联可能存在偏差。
- 当前手动记录锚点是动态计算结果，尚未作为独立关联记录持久化。
- 项目默认的轻量 ONNX 服务仍只负责实时转写，不加载 PyTorch/CAM++；需要把完整转写接口指向启用了说话人分离的 FunASR 服务。
- 当前身份纠错以整个匿名聚类为单位，尚不能只覆盖某一个文本小段。

## 下一阶段进入条件

开始阶段二之前应先确认：

- FunASR 服务能够稳定返回包含开始时间、结束时间和 `spk` 的 `sentence_info`。
- 长录音经过 VAD 分段后，说话人聚类标识能够正确合并或保持隔离。
- 明确匿名聚类在多次录音之间是否需要跨录音关联；默认不跨录音关联。
